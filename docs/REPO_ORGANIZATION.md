# Repo organization (quick map)

This repo grew through multiple iterations (local tests, Apify attempts, audits, and the working `PARALLEL/` scraper). This document is a quick “what is what” map, using folder last-modified timestamps as a rough clue for what’s current vs older.

## Current “production” paths

- `apps/coordinator/` (added 2025-12-27): Render-hosted coordinator website + API.
- `apps/worker/` (added 2025-12-27): Windows-only worker GUI + slot workers + packaging scripts.
- `PARALLEL/` (active 2025-12-27): proven local Playwright scraping engine (anti-bot warmup, persistent profiles, pickup filter, pagination, resumable runs).

## Dev support / non-production

- `tools/` (added 2025-12-27): diagnostics + analysis scripts (non-production).
- `docs/` (active): design/strategy notes and reports.

## Historical / experimental areas (kept for reference)

These folders were part of earlier builds/experiments and are not required for the distributed parallelizer MVP:

- `apify_actor_seed/`, `lowes-apify-actor/`, `deployment_package/` (2025-12-25..2025-12-27): Apify/packaging experiments.
- `lowes_scraper_final/` (2025-12-27): older “final” iteration snapshot.
- `discovered/` (2025-12-27): navigation/sitemap discovery artifacts.

## Runtime artifacts (typically ignored by git)

These are outputs/logs generated by runs (timestamps reflect local runs, not source-of-truth code):

- `scrape_output*/`, `scrape_logs/`, `logs/`
- `.playwright-profiles/`, `.playwright-profile/`, `.playwright-mcp/`
- `storage/` (local storage used by some scripts)
