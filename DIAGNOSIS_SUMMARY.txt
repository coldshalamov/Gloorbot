ROOT CAUSE
================================================================================

Missing environment variables on Gloorbot Coordinator (Render service):

  ❌ CHEAPSKATER_INGEST_URL
     Should be: https://cheapskater-dashboard.onrender.com/api/ingest/deals

  ❌ CHEAPSKATER_INGEST_API_KEY
     Should be: [your secure API key - you need to generate one]

Without these, the coordinator code at line 58-59 returns early:

  if not CHEAPSKATER_INGEST_URL or not deals:
      return  # ← EXIT HERE - never forwards to CheapSkater

================================================================================
THE FIX (CRITICAL - MUST DO THIS)
================================================================================

1. Go to https://dashboard.render.com

2. Click "gloorbot-coordinator" service

3. Settings → Environment → Add these:

   CHEAPSKATER_INGEST_URL = https://cheapskater-dashboard.onrender.com/api/ingest/deals
   CHEAPSKATER_INGEST_API_KEY = [generate any secure key, e.g., "super-secret-key-xyz"]

4. Save (service auto-redeploys)

5. Click "cheapskater-dashboard" service

6. Settings → Environment → Add/update:

   CHEAPSKATER_INGEST_API_KEY = [SAME KEY FROM STEP 3]

7. Save (service auto-redeploys)

8. Wait 2-3 minutes for redeployment

9. Your scraper data will now flow: Local → Coordinator → CheapSkater ✅
